# FRC Robot Code 2025 - REEFSCAPE

Competition robot software developed for the FIRST Robotics Competition (FRC) 2025 REEFSCAPE season.

This repository contains Java source code used in the development of an FRC competition robot. The software was developed using a command-based architecture and supports robot operation, subsystem management, driver interaction, and telemetry.

## Overview

The project was developed as part of a student-centered engineering program that emphasizes:

- Mechanical design
- Electrical systems integration
- Programming
- Iterative testing
- Collaborative problem solving

The robot was designed and refined throughout the REEFSCAPE season using an engineering design process that included prototyping, testing, analysis, and continuous improvement.

## Technologies

- Java
- WPILib
- Command-Based Programming

## Source Structure

```text
src/
└── main/
    └── java/
        └── frc/
            └── robot/
                ├── Constants
                ├── Main
                ├── Robot
                ├── RobotContainer
                └── Telemetry
```

### Key Components

**Robot**
- Manages the robot lifecycle and operating modes.

**RobotContainer**
- Organizes commands, subsystems, and operator controls.

**Constants**
- Centralized configuration and robot parameters.

**Telemetry**
- Provides diagnostic and performance reporting.

**Main**
- Entry point for robot execution.
